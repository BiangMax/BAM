# BAM 0.1.0 Alpha 2

适用于 Windows 11 x64。完整解压 ZIP 后，打开 `BAM.exe`。根目录只有 `BAM.exe`、`使用说明.txt` 和 `THIRD-PARTY` 许可目录。

本版整理了发布包结构。程序和 .NET 运行时打包进 `BAM.exe`。首次启动时，所需的原生库会解包到 Windows 临时目录。设置和日志仍使用 `%LocalAppData%\BAM`。脚本、游戏和模拟器由各项目单独提供。

Alpha 的实机限制沿用上一版。真实 MAA 心跳、同一 EXE 的模拟器多开归属和长期运行仍待验证。可执行文件未做 Authenticode 签名。
