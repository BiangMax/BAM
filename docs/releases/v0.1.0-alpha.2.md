# BAM 0.1.0 Alpha 2

适用于 Windows 11 x64。完整解压 ZIP 后，打开 `BAM.exe`。ZIP 附带独立的 SHA-256 校验文件。解压目录包含 `BAM.exe`、`使用说明.txt` 和 `THIRD-PARTY` 许可目录。

## 本版更新

- 从总览批量启动 MaaEnd、MAA 和 BBchannel。MaaEnd、BBchannel 可配置对应模拟器启动器和等待时间，脚本卡片显示倒计时。MAA 沿用自己的启动设置。已运行的脚本自动跳过，启动结果可从状态栏查看。
- 脚本卡片可显示所选模拟器实例的 CPU、工作集和最近采样时间。总览按所选指标显示资源曲线，并区分检测中、空列表和读取失败。
- 日志页显示因回放上限略过的较早记录数。启动前复核快捷方式，窗口权限提示区分令牌不可读与目标进程完整性级别较高。
- 程序和 .NET 运行时打包进 `BAM.exe`。首次启动时，所需的原生库会解包到 Windows 临时目录。设置和日志使用 `%LocalAppData%\BAM`。脚本、游戏和模拟器由各项目单独提供。

## 已知限制

- 脚本启动后的任务行为由各软件自己的设置决定。MAA 回环默认关闭，日常批量启动无需启用。
- BBchannel 收到正常关闭请求后可能收起到自己的托盘。BAM 会保留原进程状态。
- 同款模拟器实机多开归属、系统休眠后的恢复和长期运行仍待进一步验证。可执行文件未做 Authenticode 签名。
