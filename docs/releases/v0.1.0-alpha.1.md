# BAM 0.1.0 Alpha 1

这是面向 Windows 11 x64 的首个公开 Alpha 预发布。下载 `BAM-0.1.0-alpha.1-win-x64.zip`，完整解压到可写目录，再运行 `BAM.exe`。包内提供 .NET 运行时。脚本、游戏和模拟器由用户自行安装。

- 统一管理 MaaEnd、MAA 和 BBchannel 的进程、窗口与资源采样。
- 在脚本配置中可选模拟器启动入口和只读资源监控。三个脚本卡片与最近三条运行事件在默认总览首屏显示。
- MaaEnd 的可选只读任务观测按已验证版本接入。MAA 回环默认关闭，Alpha 仅提供配对、空队列与心跳。

模拟器进程归属不明确时资源显示为「—」。同一 EXE 的真实多开归属、真实 MAA 心跳、MaaEnd 整轮队列结果及长时间运行仍待验证。BAM 通过操作系统权限读取进程和窗口，部分操作可能受限。发布包未进行 Authenticode 签名。

下载资产另附 SHA-256 校验文件。解压包包含 `THIRD-PARTY` 许可和声明。
