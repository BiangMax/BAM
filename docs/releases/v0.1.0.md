# BAM 0.1.0

BAM 是面向 Windows 11 x64 的便携桌面应用。下载 ZIP 和同名 SHA-256 文件，核对摘要后完整解压，再打开 `BAM.exe`。软件包附带 .NET 运行时、BAM 许可和第三方声明。MaaEnd、MAA、BBchannel、游戏及模拟器由各项目单独提供。

## 本版更新

- 总览支持按组顺序批量启动。MaaEnd 和 BBchannel 可配置模拟器入口与倒计时，MAA 沿用自己的启动设置。
- 底栏「批量结果」逐组显示已提交待确认、已确认运行、未能确认、明确失败及有证据的跳过，并保留冲突和拒绝原因。结果随本轮进程观测更新。
- 脚本卡可显示每个已配置模拟器实例的 CPU、工作集及采样时间。总览资源曲线可切换 CPU 和内存，日志页可筛选来源及级别。

## 校验、升级和回退

- 用 PowerShell 的 `Get-FileHash -Algorithm SHA256 -LiteralPath .\BAM-0.1.0-win-x64.zip` 计算摘要，与同名 `.sha256` 文件中的首列比对。
- 从托盘菜单退出 BAM，复制整个 `%LocalAppData%\BAM` 目录作为备份。保留 Alpha 2 的解压目录，把新版本解压到新目录，然后检查设置、脚本列表、模拟器配对及监控目标。
- 回退时先退出新版 BAM，把当前配置目录改名留存，将备份复制回原位置，再启动保留的 Alpha 2。如原先没有配置，请将新版配置改名留存后直接启动 Alpha 2。

## 本地数据及已知限制

- BAM 在 `%LocalAppData%\BAM` 保存设置、管理记录和本地日志。原生运行库首次启动时会解包到系统临时目录。共享日志前请检查路径和实例信息。
- 真实任务由原软件管理。MAA 回环实验默认关闭。BBchannel 收到关闭请求后可能收起到自己的托盘。
- 可执行文件未做 Authenticode 签名。混合 DPI、系统休眠恢复、Explorer 重启和同款模拟器的多开归属以实际使用环境中的验证结果为准。
