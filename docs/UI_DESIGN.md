# BAM 桌面界面设计规范

**设计目标**　打开总览即可回答三个问题：哪些软件已启动、哪些游戏任务有可验证的活动、下一步能对哪个实例做什么。桌面图标承担软件识别，中文状态与单位承担信息表达。默认深色石墨背景、冷灰蓝表面和冰蓝强调，层次主要由留白和明度形成。界面文案使用简体中文，品牌全称和口号 One Hub, All Scripts. 放在关于页。

**实现状态**　Phase 2 及 Phase 2.1 已通过工程和视觉验收。经审核的总览、字体层级、脚本卡与控件细节是后续设计基线。额外 DPI、混合 DPI、高对比度和原生窗口交互仍有待实测项，见 [Phase 2 报告](PHASE2_REPORT.md)。

## 语义资源

所有数值为 DIP。颜色、字体、间距、圆角、阴影、图标、动画、图表与状态样式分别集中在 Desktop/Themes 的 ResourceDictionary，通过 DynamicResource 切换。业务页面只使用语义键；选中、悬停、禁用、焦点、按下状态在控件模板集中定义。

## 主窗口与响应式布局

初始建议 1200×800，最小目标 800×540，恢复上次位置前先校验显示器工作区；小屏或高缩放优先适配可用空间。48 DIP 标题栏，品牌在左，原生最小化/最大化/关闭在右。保留双击最大化、Alt+Space、拖动还原、调整边缘、Win+方向键及最大化按钮 Snap 菜单。Mica 仅作壳层背景，系统关闭透明效果、远程桌面或材质不可用时回退纯色。破坏窗口原生行为的装饰应从标题栏移除。

左侧导航标准宽 188，窗口宽不足 1050 时收为 64 DIP 图标轨道，提供 Tooltip 和独立 AutomationName；不足 900 时摘要改两列、脚本卡单列，次要操作收进菜单。宽屏采用三列等宽脚本卡，单卡可用宽度至少 260；不足则以两列或单列流式重排。内容可纵向滚动，顶部系统按钮与返回路径始终可达。

宽屏依次展示摘要、近两分钟资源曲线、脚本卡与最近事件，优先让完整卡片和部分最近事件进入首屏。窗口宽度不足 900 DIP 时，将脚本区移到图表前，使脚本身份、状态和管理入口更早可见。任务摘要显示“可检测 n 项”；没有可靠适配时写“暂无可检测任务”，不能填 0 个执行中。异常数附可跳转的筛选入口，采样断开时显示最后更新时间。资源范围写“已确认脚本主进程”，图表切换 CPU/内存，不混用双单位纵轴。CPU 轴 0–100%，内存轴显示 MiB，从 0 起并平滑调整上界。单个环形缓冲保留 120 秒样本，绘制仅在新点到达时进行，悬停及键盘详情能读到采样时间和数值。

### 脚本卡、操作与反馈

卡头为原图标、软件名、游戏名和版本。卡身并排呈现“软件进程”和“游戏任务”两个独立状态，任务有可靠活动时才展开名称或步数。底部同一基线放 CPU、工作集、运行时长。窄屏单列卡把按钮组放到资源指标右侧，主按钮按内容取宽。软件停止时资源显示“—”，未知值提供原因。缺路径用“重新定位”，权限不足用“无法读取”，过期样本注明时间。BBchannel 卡同样保留任务状态，显示“未接入任务检测”。百分比需要有可信分子分母，只有阶段名称就显示阶段。

| 场景 | 主操作及反馈 |
|---|---|
| 未启动、入口有效 | “启动软件”。若读到启动即执行，可在确认中写明会运行原配置、可能打开模拟器。启动中锁定该实例的重复操作。 |
| 已运行 | 主操作“打开窗口”；详情、查看日志、正常关闭、重启置于次级菜单。窗口不可见时说明原因及原软件托盘入口。正常关闭超时显示“软件仍在运行”。 |
| 危险操作 | “强制结束软件”独立展示，确认时给出软件名、实例和未保存任务风险。按钮明确写“强制结束”。“停止游戏任务”只在已验证的任务适配器中出现。 |
| 任务控制 | 点击后显示“等待任务信号”或“指令已回报”，观察到对应事件才更新游戏任务行。失败提示包含可采取的操作，详情可跳转日志。 |
| 操作冲突或权限拒绝 | 保留原卡和已知状态，在卡内解释“目标已重启”“权限不足”等原因，提供刷新。通知不夺取焦点。 |

正在运行用播放形态及“已启动”；任务执行、完成、失败分别有自己的图标和中文标签。正常停止为中性色，未知为空心圆和说明。成功反馈短暂呈现；需要处理的错误保留至已读或原因消失。避免把整个卡片染成绿色或红色。

## 页面与交互

| 页面 | 布局与规则 |
|---|---|
| 脚本管理 | 顶部“重新检测”“手动添加”。列表和详情按内容取高，详情使用分隔线组织安装信息、能力和操作，版本集中在身份栏。选中后右侧详情或窄屏子页展示路径、工作目录、参数及来源。多匹配逐项选择，保存前检验文件和目录。 |
| 运行日志 | 工具条选择 BAM/软件、级别、搜索和自动滚动；中间虚拟列表，右侧或展开行显示详情。用户向上翻阅时停止跟随，显示新增条数。支持复制选中记录、脱敏导出及上限提示。 |
| 设置 | 按外观、监控、托盘与通知、脚本配置、关于分组。展示采样间隔、关闭窗口行为；可选“跟随系统、浅色、深色”。开机自启动及远控仅在对应功能可用时出现。关闭到托盘首次说明，托盘菜单包含打开总览、状态、退出 BAM。 |
| 任务计划（后续） | 下一次运行、队列、依赖设备和冲突并列；编辑区显示时区、错过执行策略、任务后动作。未接入的脚本不提供任务类计划。 |
| 数据统计（后续） | 时间范围、脚本过滤、运行时长和已证实的任务结果。图表附样本覆盖和未知数。MVP 导航只放实际可用页面。 |

初次加载显示与真实布局同尺寸的占位和“正在检测”，超过预期给出取消/重试。空列表显示“尚未添加脚本”，主操作为自动检测，次操作为手动添加。某一脚本出错仅替换该卡的受影响区域。离线、无权限、未支持分别使用不同文案。Tooltip 说明动作、资源口径或禁用原因，键盘可聚焦替代说明。

## UI 验收

- 在 100%、125%、150%、200% 和双屏不同 DPI 下拖动窗口，标题按钮、图标和文字清晰，操作不会被裁掉。最大化、贴靠、还原、系统菜单、关闭和托盘还原均按 Windows 习惯工作。
- 深色、浅色、跟随系统、高对比、关闭透明、关闭动画各走一遍。普通文字对比度至少 4.5:1，大字和重要非文字控件至少 3:1；焦点描边 2 DIP，不能仅靠颜色表达状态。
- Tab 顺序为导航、页操作、内容卡及其操作；方向键选择列表，Enter/Space 执行，Esc 关浮层并返还原焦点。读屏能读出控件名、状态和资源单位；流式日志与 CPU 刷新不连续打断播报。
- 用停止、启动中、无权限、无窗口、过期日志、缺少任务能力、真实失败七组快照验收。资源列数字不跳位，未知值不以零替代，非幂等按钮无重复提交。
- 检查键盘与鼠标两种导航、窄屏长中文名称、错误长文本、虚拟化滚动及托盘静止。开发样例标记“演示数据”，发布构建只能接入真实观察源。
